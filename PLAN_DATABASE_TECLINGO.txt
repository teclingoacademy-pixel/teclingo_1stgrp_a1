RESUMEN DEL PROYECTO
---------------------
TECLINGO PRO 1.1 es una plataforma premium de aprendizaje de ingles con:
- Frontend: React 19 + TypeScript + Vite + Tailwind CSS v4
- Backend: Express.js (TypeScript) en puerto 3000
- ORM: Prisma 6.19.3
- Base de Datos: PostgreSQL 15 (via Docker)
- AI: Groq SDK (Llama 3.3 70B)
- Despliegue: Vercel (serverless) + Docker (local dev)
